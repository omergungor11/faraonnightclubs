# Faraon Night Club - Kıbrıs Premium Night Club Katalog

Kıbrıs'ın en prestijli night club deneyimi olan **Faraon Night Club** için modern, hızlı ve kullanıcı odaklı web platformu. Bu proje, Kıbrıs gece hayatına dair güncel kataloglar, VIP hizmetler ve detaylı kulüp rehberleri sunar.

## 🚀 Teknolojiler

- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## ✨ Özellikler

- **Modern UI/UX:** Altın ve karanlık tema ile premium bir atmosfer.
- **Dinamik Katalog:** Görsel ağırlıklı, interaktif gece kulübü listeleri.
- **Hızlı Erişim:** Ana sayfada ve tüm sayfalarda yüzen WhatsApp katalog hattı.
- **SEO Uyumlu:** Semantik HTML, optimize edilmiş meta etiketleri ve hızlı sayfa yüklemeleri.
- **Responsive:** Mobil, tablet ve masaüstü cihazlar için tam uyumlu tasarım.

## 🛠️ Kurulum

Yerel geliştirme ortamında çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install
# veya
pnpm install

# Geliştirme sunucusunu başlatın
npm run dev
```
